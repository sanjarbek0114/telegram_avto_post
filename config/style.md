# Post stili
- Til: o'zbek (lotin), ota-onalar va o'smirlarga do'stona, ishontiruvchi ohang.
- Oddiy matn (HTML/Markdown yo'q). Bo'limlar emoji bilan boshlanadi, ro'yxat qatorlari ham emoji bilan.
- Tuzilma: diqqat tortuvchi sarlavha savol/da'vo → hayotiy vaziyat → asosiy bo'limlar → qisqa xulosa → hashteglar.
- Apostrof sifatida ’ belgisi ishlatiladi (o’, g’).
